# Reference lists

Ready-to-use gene / transcript lists distributed with SMART.

## OncoKB canonical transcripts
| File | Description |
|------|-------------|
| `oncokb_transcripts.txt` | OncoKB's canonical RefSeq **NM** transcript per curated gene, one per line. Pass directly to the pipeline as `--transcripts-file` (Tier 1 of the transcript whitelist). |
| `oncokb_transcripts_summary.tsv` | The same list with extra context — gene symbol, NM accession, Ensembl transcript — for review. |

Both are produced by [`utils/get_oncokb_transcripts.py`](../utils/get_oncokb_transcripts.py); re-run it to regenerate against the current OncoKB release.

## TSO500 panel lists
| File | Description |
|------|-------------|
| `TSO500_genes_list.txt` | Genes covered by the TruSight Oncology 500 panel. |
| `TSO500_transcripts_list.txt` | Preferred RefSeq NM transcript per TSO500 gene — a ready-made `--transcripts-file` whitelist. |
| `TSO500_transcript_MANE.txt` | TSO500 transcripts with their MANE Select mapping. |
| `TSO500_transcript_list_explained.md` | Notes explaining how the TSO500 transcript list was compiled. |

## SVIG-UK classification resources
Used by the Tier 4 oncogenicity classifier, [`scripts/svig_uk_classifier.py`](../scripts/svig_uk_classifier.py). Each has a command-line override, so a laboratory can substitute its own table; the paths below are the defaults.

| File | Description |
|------|-------------|
| `svig_uk_canonical_variants.tsv` | The SVIG-UK canonical (likely) oncogenic variant list — 160 entries over 39 genes, each with its transcript, HGVSc, protein change, assessment and a `match_rule` (`protein`, a `genomic:chr:pos:ref:alt` key, or `flt3_itd`). Always used by the classifier (`--canonical`); also read by [`scripts/post_analysis.py`](../scripts/post_analysis.py), which raises the `svig_canonical` annotation flag for a variant at one of the genomic-keyed positions, so a row a consequence filter would drop is kept on that evidence. |
| `svig_uk_vcep_population_thresholds.tsv` | ClinGen VCEP population-frequency rules for 15 hereditary cancer genes, from the CSpec registry, with the VCEP id, version and status recorded per gene. Drives O3 (PM2) and B1 (BA1 → stand-alone, BS1 → strong). `--vcep-thresholds`. |
| `svig_uk_functional_assays.tsv` | Functional-assay parameters for O10 / B6: the <25 %-of-wild-type abnormality threshold, the per-assay strength with the calibration justification, and provenance (source, PMID, licence, MaveDB URN). `--functional-assays`. |
| `svig_uk_functional_assay_scores.tsv` | The measurements themselves — one row per variant (`assay_id`, protein change, `pct_wt`), 2,314 rows for the TP53 transactivation assay currently included. Found beside the parameter file, not passed separately. |
| `svig_uk_gene_specific_splice.tsv` | Gene-specific splice provisions that neither the ±1,2 definition nor in silico predictors capture — the synonymous changes at the last base of TP53 exons 4, 6 and 9, which SVIG-UK §7.11 classes as driver variants. Routed through the O2 exon-skipping branch, with a review flag. `--gene-specific-splice`. |

All five are copied into the Docker image, so a container run uses them without mounting anything: `svig_uk_canonical_variants.tsv`, `svig_uk_vcep_population_thresholds.tsv`, `svig_uk_functional_assays.tsv`, `svig_uk_functional_assay_scores.tsv` and `svig_uk_gene_specific_splice.tsv`.

**Only the first two used to be.** The classifier resolves each default path relative to `scripts/`, so inside a container the other three were simply not found — and their absence does not fail a run. O10/B6 fell back to the OncoKB mutation-effect proxy at supporting strength (1 point where the shipped assay table gives 2), and the TP53 exon 4/6/9 synonymous provision below was never applied. Nothing in the output said the route had been unavailable, so the same variant could be classified differently inside and outside a container with no visible reason. They are the guideline's own content, already in this directory and under no licence restriction, so there was no reason for them to be left out.

`tests/verification5/test_sample_columns.py` now asserts that the Dockerfile copies every list the classifier names a default for, and `tests/verification5/test_docs_name_real_things.py` that this file names every list the Dockerfile copies.

`svig_uk_functional_assays.tsv` and `svig_uk_functional_assay_scores.tsv` are regenerated by [`utils/build_functional_assays.py`](../utils/build_functional_assays.py) (`--check` verifies the stored files without network access). The canonical variants, VCEP thresholds and gene-specific splice tables are maintained by hand from the guideline and the CSpec registry; the VCEP, functional-assay and splice tables carry their provenance in `#` comment lines at the top of the file.
